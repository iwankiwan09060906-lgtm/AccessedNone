# MANUAL_STEPS

사용자가 에디터에서 직접 해야 하는 작업입니다. 완료하면 "했어"라고 알려주세요.

## #1 에디터 재시작 (MCP 연결 + Live Coding 완전 해제) — ✅ 완료 (2026-11-14)

1. 언리얼 에디터에서 파일 → 종료 (저장할 것이 있으면 저장)
2. `D:\UnrealEngine\AccessedNone\AccessedNone.uproject` 더블클릭으로 다시 열기
3. Windows 방화벽 팝업이 뜨면 **개인 네트워크 허용** 클릭
4. 편집 → 프로젝트 세팅 → 플러그인 → Python → **Enable Remote Execution** 체크 확인, **Multicast Bind Address** = `0.0.0.0` 확인
5. 편집 → 에디터 개인설정 → 일반 → Live Coding → "Live Coding 활성화"가 **꺼져 있는지** 확인

## #2 Stage 1 직접 플레이 확인 (조작감) — 대기 중

자동 테스트가 보스 흐름 전체(1% 데미지 → 감마 파훼 → 약공격 10회 처치, 전투 중 ESC ×0.15)를 검증했습니다.
아래는 **손으로만 확인할 수 있는 조작감** 항목입니다.

1. 콘텐츠 브라우저 → `Content/Maps/L_Dev_Sandbox` 더블클릭 → 상단 플레이 버튼 옆 **⋮(또는 ▾) → 독립형 게임(Standalone Game)** 으로 실행
   (일반 PIE에서는 `ESC`가 플레이 종료 키라서 메뉴 확인이 안 됩니다)
2. 조작 확인: `WASD` 이동 / `Space` 구르기 / `F` 점프 / 마우스 휠 클릭 락온 / 좌클릭 약공격 / `Shift`+좌클릭 강공격(0.8초 후 2배 데미지) / `R` 회복약
3. 앞쪽 허수아비(Narbash) 근처로 걸어가면 인카운터 시작. 허수아비는 공격하지 않음 — 처치하면 쓰러진 뒤 2초 후 사라지고 잠시 뒤 부활
4. `ESC` → 설정창이 열리고 세계가 느려짐(×0.15). 다시 `ESC`(또는 `닫기`)로 닫기
5. 감마 파훼: `F10`(엔진 콘솔)을 열고 `AN_Set Gamma 0.95` 입력 → 약 2초 뒤 약점화 → 약공격 10회에 처치
6. 상태 확인: `F10` → `AN_Status` (출력 로그 창에 표시). 판정 박스 표시: `an.Debug.Hitbox 1`
7. 사망하면 `YOU DIED` 화면 → `다시하기`로 시작 지점에서 부활 (보스는 대기 상태로 리셋됨)
8. 이동 속도·구르기 거리·공격 타이밍 등 어색한 점이 있으면 알려주세요 (`프로젝트 세팅 › Accessed None Tuning`에서 바로 조정 가능)

## #3 Paragon 캐릭터 확인 — 대기 중
`L_Dev_Sandbox`를 Standalone으로 실행 → 숫자키 `1`~`4`로 캐릭터 교체. 이동/대시/점프/구르기에서 걷기·달리기 애니메이션이 재생되는지, 발이 땅에 맞는지 확인. 공격(약/강)·피격·사망 모션도 재생되는지

## #4 Stage 2 직접 플레이 확인 (오프닝) — 대기 중

자동 테스트(`Flow.Opening`)가 타이틀 → 페이즈 1~5 → 스테이지 1 진입 전체 흐름을 검증했습니다(오류창은 코드로 숫자를 교환).
아래는 **손으로만 확인할 수 있는 항목**입니다.

1. 에디터 상단 플레이 버튼 옆 **⋮ → 독립형 게임(Standalone Game)** 으로 실행 (기본 맵이 `L_Title`)
2. 타이틀에서 **새 게임** 클릭
3. 튜토리얼 팝업이 행동마다 넘어가는지 확인 (WASD → Space → 좌클릭 → Shift+좌클릭 → R)
4. 앞쪽 엘베른에게 다가가 처치 → 금빛 + `DEMON VANQUISHED` → BGM이 늘어지며 멈춤 → 하늘 균열 → 방어 개체 낙하 → 로그 → 강제 사망
5. 중간에 `ESC`를 눌러 설정창이 열리고 밝기 슬라이더가 즉시 화면에 반영되는지 확인
6. 오류창에서:
   - 버튼 3개 클릭 → 창이 흔들리고 "권한 없음"만 표시
   - 숫자 위에 마우스 → 손 모양 커서
   - **드래그 & 드롭**: 분모(99999999)를 분자 자리로 끌어다 놓기 → 오버플로우 → 스테이지 1
   - (다시 해볼 때) **클릭-클릭**: 숫자 클릭(집기) → 다른 숫자 클릭(놓기), 창 밖 클릭 시 원위치
   - 30초/60초 동안 가만히 두면 디버거 힌트가 나오는지
7. 소리: BGM, 디버거 타이핑 클릭음이 들리는지

## #5 캐릭터별 공격 확인 — 대기 중
`L_Dev_Sandbox` Standalone → 숫자키로 캐릭터 교체 후 허수아비 공격.
- 1·4번 근접 사거리 동일, 3번은 조금 더 김
- 2번: 화면 중앙 십자선(적 위면 빨강)과 조준 지점 마커, 좌클릭 화살 / Shift+좌클릭 강화 화살. 쏘는 동안만 과녁 쪽을 보고 끝나면 이동 방향으로 돌아오는지

## #6 Stage 3 직접 플레이 확인 (스테이지 1) — 대기 중 (2026-11-15 개정 반영)
자동 테스트(`Stage1.Encounters`)가 E1·E2의 불합리 → 사망 힌트 → 파훼 → 처치를 검증했습니다. 손으로 확인할 항목:
1. 콘텐츠 브라우저 → `Content/Maps/L_Stage1_DarkGrove` → 독립형 게임 실행 (눈 내리는 야영지에서 시작)
2. 모닥불 근처 붉은 구 앞에서 `[E] 브레이크포인트` → "브레이크포인트 설정됨"
3. 얼음 기둥 사이 룬 비석 앞에서 `[E] 살펴보기`
4. **E1** 고목 숲에 들어가면 어두워짐(감마 20%). 눈 반짝임이 보이는지, 기습에 죽으면 `YOU DIED` 화면 → `다시하기`로 브레이크포인트에서 부활하는지, `메인 메뉴로`가 타이틀로 가는지
5. `ESC` › 그래픽 › 밝기를 끝까지 → 화이트아웃 후 **암살자 3체**가 드러나고 1초 뒤 반격 → 근접전으로 3체 처치(각 약공격 3회) → 마지막 1체가 쓰러진 뒤 밝기가 서서히 돌아옴. **난이도가 적당한지** 알려주세요
6. 긴 절벽 협로를 지나 두 번째 브레이크포인트 → 회색 박스 파편 → 넓은 광장
7. **E2** 광장에서 가시 기사가 18m 안에 들어오면 매우 빠르게 돌진해 일격에 죽이는지, 구르기로 피할 수 있는지, 기사를 때리면 가시가 튀어나오며 즉사하는지
8. `ESC` › 품질 › 모델링 품질 → 최하 → 가시가 사라지고 **회색 박스로 된 기사**가 움직이는지, 속도가 느려지고 일반 공격이 들어가는지(약공격 10회)
9. 설정창: 7개 탭 전환, 페이지 스크롤, 키 설정 버튼 클릭 → 키 입력 시 표시가 바뀌는지(ESC = 취소), `기본값 복원`, `메인 메뉴`, `게임 종료`
10. 타이틀로 나갔다가 `이어하기` → 마지막 브레이크포인트에서 시작하는지
